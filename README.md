## ⭐ Featured Engineering Projects

### 🧠 Distributed Key-Value Store
**[Distributed Key-Value Store with Tunable Consistency](https://github.com/bhushanasati25/Distributed-Key-Value-Store-with-Tunable-Consistency)**

Dynamo-inspired distributed storage system implementing consistent hashing, replication, tunable quorum consistency, gossip-based failure detection, hinted handoff, read repair, vector clocks, and Bitcask-style storage.

**Stack:** Go · Distributed Systems · Consistent Hashing · Replication · Quorums · REST

### 🛡️ Real-Time Fraud Detection Platform
**[Real-Time Fraud Detection Service](https://github.com/bhushanasati25/Real-Time-Fraud-Detection-Service)**

Event-driven fraud detection platform combining rule-based detection with ML scoring through independently deployable microservices.

**Stack:** Java · Spring Boot · Kafka · Python · FastAPI · PostgreSQL · Redis · Docker

### 📦 Distributed Order Fulfillment Platform
**[Distributed Order Fulfillment Platform](https://github.com/bhushanasati25/Distributed-Order-Fulfillment-Platform)**

Microservices platform using Saga-based distributed transactions, compensating actions, idempotency, concurrency control, Kafka, Kubernetes, Terraform, and observability.

**Stack:** Go · Kafka · Redis · Kubernetes · Terraform · Microservices

### 📡 Distributed Network Observability
**[Titan – Distributed Real-Time Network Observability Platform](https://github.com/bhushanasati25/Titan-Distributed-Real-Time-Network-Observability-Platform)**

Systems-focused platform for real-time telemetry, distributed monitoring, service health, and performance analysis.

### 📈 Scalable Data Pipeline
